# Pirate Talk

Pirate Talk is a Chrome and Brave browser extension that transforms common website error messages into pirate-themed language. Instead of displaying plain, repetitive error text, Pirate Talk replaces it with entertaining pirate dialogue while preserving the original meaning.

## Features

- Translates common website error messages into pirate speak.
- Lightweight and fast.
- Works on Chromium-based browsers, including Chrome and Brave.
- Automatically runs on supported webpages.
- Built using Manifest V3.

## Example

**Before**

```
404 Not Found
403 Forbidden
500 Internal Server Error
An error occurred.
```

**After**

```
Arrr! This page be lost at sea, mate!
Ye be forbidden from enterin' these waters!
The ship's engine be on fire! The crew must be fixin' it.
Arrr! Somethin' went terribly wrong.
```

## Installation

1. Download or clone this repository.
2. Open `chrome://extensions` or `brave://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the Pirate Talk project folder.
6. Reload any open webpages.
