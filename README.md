# Pirate Talk 

Pirate Talk is a Chrome/Brave browser extension that replaces boring website error messages with fun pirate-themed messages.

## Features
- Translates common error messages into pirate language
- Works on supported websites
- Lightweight and fast
- Easy to install in Chromium-based browsers

## Example

Before:
404 Not Found

After:
Arrr! This page be lost at sea, matey!

## Installation

1. Clone this repository.
2. Open `brave://extensions` or `chrome://extensions`.
3. Enable Developer Mode.
4. Click **Load unpacked**.
5. Select this project folder.

## Technologies

- JavaScript
- HTML
- CSS
- Chrome Extension Manifest V3
